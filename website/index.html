实时预览、源码编辑与偏好设置，看看墨笺的实际界面。

01

完整能力，安静呈现

围绕 Markdown 写作本身设计，每项功能都留在需要它的位置。

Aa

无缝实时预览

标题、列表、引用、代码与表格在同一编辑面中完成输入和排版。

⌘

组件化编辑

代码块、表格、任务列表、公式与图表均可直接点击编辑。

⌕

文档与工作区检索

支持当前文档查找替换，以及跨工作区按文件名和内容搜索。

∑

专业 Markdown

支持 GFM、KaTeX 数学公式、Mermaid 图表与 YAML Front Matter。

◫

本地工作区

多根目录文件树、大纲、最近文档与本地设置，内容始终由你掌控。

⇧

导出与更新

直接导出 HTML（Windows/macOS 也支持 PDF），并可在应用内检查、下载和安装新版本。
